# Application icon

Original artwork for this project, generated with the built-in image generation
tool at the project owner's request. No dictionary screenshots, CASIO trademarks,
stock icons or third-party artwork were used as input. Distributed with this
project's MIT License; this is not a claim of exclusive copyright in AI output.

PNG is the approved master. ICO and ICNS are packaging derivatives of the same
artwork, produced with `packaging/prepare_icons.py` using macOS sips/iconutil.
Alpha transparency is preserved. Build PCs use the supplied assets directly.

Generation prompt:

> Use case: logo-brand. Desktop application icon for EX-word Screen Capture,
> square composition for macOS, Windows and Linux. An original icon showing a
> small clamshell electronic dictionary projecting its screen to a larger PC
> monitor. The dictionary has an upright hinged display, compact dense physical
> keypad and a small secondary touch panel; the PC is a monitor on a stand.
> One bold directional arrow connects the displays, which share an abstract cyan
> pattern. Minimal polished raster illustration, bold geometry, subtle depth,
> strong silhouette readable at small sizes, navy/silver/cyan and a contrasting
> arrow. Centered on a rounded navy tile with transparent outer background.
> Two devices only, no real dictionary contents, photographs, text, letters,
> numbers, CASIO logo, trademarks, watermark, cable clutter or wireless symbol.
